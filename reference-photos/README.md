# Reference photos

- `ef88-right-side.jpg` — EF88 right side, background removed. Source: KarmaKangaroo, Wikimedia Commons, CC0. Copied from the earlier `ef88-firing-cycle` project; nothing was downloaded for this project.
- `ef88-right-side-depth.png` — depth map for the same photo (white = thickest), also from the earlier project. Used to give the photo body its 3D relief.

`../ef88-assets.js` is these two files embedded as data URIs. Regenerate it if you replace the images.

- `ef88-right-side-texture.jpg` — the photo with its bright cut-out fringe replaced by the nearest body colour, so the top, bottom and edges of the 3D body do not pick up a white outline. This is the file actually embedded.
