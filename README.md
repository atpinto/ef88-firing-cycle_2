# EF88 Firing Cycle (v2)

Interactive three.js view of the EF88 Austeyr firing cycle: a photo-based exterior that can be made solid or see-through, over a simplified model of the trigger, hammer, bolt, carrier and gas system. Play, pause, slow down and scrub through twelve named phases.

**Live page:** https://atpinto.github.io/ef88-firing-cycle_2/

Created by LT Armando Teixeira Pinto, 2HB D-COY 1 PL.
