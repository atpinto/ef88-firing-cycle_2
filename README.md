# EF88 Firing Cycle (v2)

Interactive three.js view of the EF88 Austeyr firing cycle: a photo-based exterior that can be made solid or see-through, over a simplified model of the trigger, hammer, bolt, carrier and gas system. Play, pause, slow down and scrub through twelve named phases.

**Live page:** https://atpinto.github.io/ef88-firing-cycle_2/

Created by LT Armando Teixeira Pinto, 2HB D-COY 1 PL.

## Image credits

- The main viewer uses the weathered exterior renders supplied for this project. Both side views include the magazine. The top, underside, front and rear references provide the finish between the side profiles.
- The separate Studio view uses the CC0 right-side photograph by KarmaKangaroo. [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:EF88_(Enhance_F88_%27Austeyr%27).png)

## Exterior detail pass

The side-photo silhouettes are retained while the optic, barrel and foregrip
use rounded visual cross-sections. Restrained relief follows molded magazine
and grip details without turning the stock's paint wear into surface bumps.
The optic end faces use the supplied front honeycomb and rear lens references.
Front, Rear and Optic camera presets support close inspection; all added faces
follow the existing body transparency setting.

This is a visual reconstruction from the supplied renders, not a dimensionally
accurate model. The firing-cycle animation is unchanged.
